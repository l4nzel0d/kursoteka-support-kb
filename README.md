# База знаний технической поддержки «Курсотека»

Репозиторий поддерживает работу службы технической поддержки платформы онлайн-курсов
«Курсотека» по методологии **Knowledge-Centered Service (KCS)**.

Основной принцип методологии: статья базы знаний — побочный продукт решения обращения,
а не отдельная работа, выполняемая позже. Разобрав обращение пользователя, инженер
заводит здесь задачу по KCS-шаблону, и она автоматически становится статьёй в BookStack.

## Цикл знаний

```
Обращение пользователя
        ↓
Задача по KCS-шаблону в этом репозитории
        ↓
GitHub Actions → REST API BookStack
        ↓
Статья в книге «База знаний технической поддержки»
        ↓
Поиск и повторное использование при следующем таком же обращении
```

## Как завести знание

1. Issues → New issue → «KCS-статья базы знаний».
2. Заполнить разделы: **Проблема**, **Причина**, **Решение**, **Ссылки**, **Метки**.
   В разделе «Проблема» описывать симптом словами пользователя — именно по нему
   инженер первой линии будет искать готовый ответ.
3. Сохранить задачу. Статья появится в базе знаний в течение минуты.
4. При появлении новых сведений править саму задачу: статья обновляется, а не
   дублируется. Закрытие задачи переводит статью в статус «решено».

Задачи без метки `knowledge` рабочим процессом не обрабатываются, поэтому обычные
задачи разработки в базу знаний не попадают.

## Состав репозитория

| Файл | Назначение |
| --- | --- |
| `.github/ISSUE_TEMPLATE/kcs_issue.md` | KCS-шаблон задачи с обязательными разделами |
| `.github/ISSUE_TEMPLATE/config.yml` | Запрет пустых задач, ссылка на базу знаний |
| `.github/workflows/bookstack-sync.yml` | Рабочий процесс, реагирующий на события задач |
| `.github/scripts/sync-page.js` | Сборка статьи и обращение к API BookStack |
| `.github/scripts/package.json` | Зависимость `marked` для преобразования Markdown в HTML |

## Секреты репозитория

| Секрет | Значение |
| --- | --- |
| `BOOKSTACK_URL` | Внешний адрес BookStack без завершающей косой черты |
| `BOOKSTACK_API_ID` | Идентификатор API-токена пользователя `github-bot` |
| `BOOKSTACK_API_SECRET` | Секрет API-токена |
| `BOOKSTACK_BOOK_ID` | Идентификатор книги, в которой создаются статьи |
